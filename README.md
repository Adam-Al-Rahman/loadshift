# Loadshift

Loadshift explores how a factory can reduce electricity costs by planning when its machines run and how its electricity demand is supplied.

A factory may get electricity from rooftop solar, the grid, and backup generators. Grid prices change throughout the day, while production jobs have deadlines and machines have operating limits. Running machines at the wrong time can increase electricity costs and peak demand.

Loadshift aims to find production schedules that meet required deadlines while making better use of available solar power, grid electricity, and generators.

The goal is simple: **meet production requirements at a lower electricity cost without violating operational constraints.**


**Status**: Early development. The Rust API workspace and health endpoint are in place. The production scheduling model and optimization engine are still being designed.
